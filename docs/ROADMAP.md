# ScanMaster AI 12 个月路线图

严格遵循版本顺序；前一版本质量门禁未关闭，不启动后一版本。

| 月份 | 版本 | 核心交付 |
|---|---|---|
| 1–2 | V0.1 | 扫描、增强、页面编辑、PDF、本地基础文档列表 |
| 3 | V0.5 | 中英文 OCR、复制、OCR 内容搜索 |
| 4 | V1.0 | 证件模板系统、身份证、护照、银行卡、营业执照 |
| 5–6 | V1.5 | 文件夹、标签、全文资料库、批量操作 |
| 7–8 | V2.0 | PDF 转换、合并、拆分、压缩、加密、签名和水印 |
| 9–10 | V3.0 | 本地优先的 AI 分类、命名和摘要 |
| 11–12 | V4.0 | CloudKit 同步、iPhone/iPad/Mac、Face ID、加密、商店发布 |

每个版本必须交付产品说明、架构说明、测试报告、已完成列表和下一版本计划，并保留旧功能的回归测试。
