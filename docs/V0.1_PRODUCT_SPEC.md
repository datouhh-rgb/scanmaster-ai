# ScanMaster AI V0.1 产品说明

## 版本目标

V0.1 解决“用最少步骤把纸质文件变成清晰、可分享的多页 PDF”这一条核心链路，并为后续 OCR 和资料管理建立稳定数据边界。

V0.1 不包含 OCR、证件专用模板、文件夹/标签管理、PDF 签名、AI 分类和云同步。

## 首页

首页提供四个明确入口：

1. 扫描文件：V0.1 主入口，采用最大尺寸高对比按钮。
2. 扫描证件：展示 V1.0 标识和版本预告，不伪装为已完成功能。
3. 图片识别：展示 V0.5 标识和版本预告。
4. 我的文档：进入 V0.1 基础文档列表。

用户打开应用后无需注册、登录或完成引导即可点击扫描，目标是在正常冷启动后 3 秒内进入相机。

## 核心流程

```text
首页
  → 文档相机自动识别/拍摄/矫正
  → 多页编辑（添加、重拍、删除、排序、旋转）
  → 逐页选择增强模式
  → 命名并选择压缩质量
  → 生成 PDF
  → 本地预览、分享、合并或拆分
```

## 扫描与页面编辑

VisionKit 文档相机负责实时边缘、拍摄角度、光线提示、自动拍摄、自动裁剪和透视矫正。用户可以一次连续拍摄多页。

扫描结束后支持：

- 添加新页面。
- 重拍当前页面；一次重拍多页时，第一页替换当前页，其余页面追加。
- 删除页面，但不允许删除最后一页。
- 拖动调整页面顺序。
- 以 90° 为步长旋转页面。
- 重新选择滤镜并查看低分辨率实时预览。

## 图像增强

| 模式 | 目标 |
|---|---|
| 原图 | 仅执行方向校正和输出压缩 |
| 增强 | 提升暗部、压制高光、增加对比和锐度 |
| 黑白 | 高对比黑白文档 |
| 灰度 | 保留平滑灰阶层次 |
| 票据 | 去色、提高曝光和对比，强化小字与浅色背景 |

预览使用小文件尺寸以保证交互速度；保存时按用户选择重新处理原始扫描数据，避免预览图造成清晰度损失。

## PDF 与文档

- 文件名经过非法字符清理并限制为 80 个字符。
- 实际 PDF 文件名与界面名称保持一致，重命名时同步移动文件。
- 压缩提供高清、平衡和小文件三档。
- 页面统一排版到 A4 画布并保持原始宽高比。
- 支持 PDFKit 连续预览和系统分享面板。
- 支持将两份以上文档合并为新 PDF。
- 支持将多页文档拆分为多个单页 PDF，保留原文档。
- 已保存文档可以从详情页重新编辑页面；保存时原位更新文档和 PDF，不创建意外副本。
- 删除文档时同时删除数据库记录、页面图片和 PDF 文件。

## V0.1 验收标准

- iPhone 真机可以完成单页和三页连续扫描。
- 页面输出已由 VisionKit 自动裁剪并矫正透视。
- 五种增强模式均能生成可读取 JPEG。
- 页面添加、重拍、删除、排序和旋转结果与 PDF 顺序一致。
- 三档压缩均能生成可打开 PDF。
- PDF 实际页数与编辑页数一致。
- 重命名后分享文件名同步更新。
- 合并和拆分不会删除源文档。
- 已保存文档调整页面后保持原文档 ID 和创建时间，并清理已删除页面文件。
- 重启应用后文档列表仍可读取。
- 拒绝相机权限、图片处理失败或数据库失败时给出可理解的错误，不崩溃。
